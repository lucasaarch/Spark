# Spark 1.3.1

Spark 1.3.1 improves terminal organization and Git feedback.

## Highlights

- Drag a terminal pane onto another tab to move it. The destination tab highlights while the pane can be dropped there.
- Reorder tabs by dragging them in the tab bar.
- Keep the terminal header controls aligned when the current Git branch has a short name.
- Show which Source Control operation is running, with a progress indicator, until it completes or fails.

## Install

Requires **macOS 14 Sonoma or later**, on Apple Silicon or Intel.

1. Download **Spark-1.3.1.dmg** below.
2. Open the disk image and drag **Spark** into **Applications**.
3. Launch Spark and use your existing shell and tools.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP is provided for Sparkle updates; `SHA256SUMS` contains checksums for both downloads.

Codex and Claude Code are optional, installed and authenticated separately. Start them in a new zsh pane to connect metrics. Available fields depend on the CLI version and configuration. Restored workspaces open fresh shells; commands and agents are not automatically restarted.
