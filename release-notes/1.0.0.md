# Spark 1.0.0

The first public release of Spark: a native, open-source macOS terminal for your shell, your AI agents, and your next big idea.

## Highlights

- Native SwiftUI and AppKit interface with GPU-powered terminal rendering.
- Persistent workspaces, tabs, split panes, layout presets, and restored window geometry.
- Codex and Claude Code activity indicators, context and usage metrics, and macOS notifications.
- An activity panel to find running agents and resume recent CLI conversations.
- Per-terminal Git worktrees with generated names and guarded merges back to the original branch.
- Native code review with a file tree, syntax highlighting, live filesystem updates, and recovery copies when discarding changes.
- A searchable command palette and keyboard shortcuts throughout the app.
- Automatic updates through Sparkle.

## Install

Requires **macOS 14 Sonoma or later**, on Apple Silicon or Intel.

1. Download **Spark-1.0.0.dmg** below.
2. Open the disk image and drag **Spark** into **Applications**.
3. Launch Spark and use your existing shell and tools.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP is provided for Sparkle updates; `SHA256SUMS` contains checksums for both downloads.

Codex and Claude Code are optional, installed and authenticated separately. Start them in a new zsh pane to connect metrics. Available fields depend on the CLI version and configuration. Restored workspaces open fresh shells; commands and agents are not automatically restarted.
