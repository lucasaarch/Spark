# Spark 1.2.0

Spark 1.2 brings Git staging and commits into Spark, with a focused Source Control panel and a smoother code review workflow.

## Highlights

- Stage or unstage individual files, stage all changes, and commit staged work without including unstaged edits.
- Generate commit subjects from staged changes with Codex or Claude Code, selectable in Settings.
- Review changed files with status badges, mark files as reviewed, and move to the previous or next file.
- Keep Activity or Source Control open when reopening a workspace, and see an animated glow while an agent is working.
- Delete recent conversations from Activity and check for Spark updates from Settings.

## Install

Requires **macOS 14 Sonoma or later**, on Apple Silicon or Intel.

1. Download **Spark-1.2.0.dmg** below.
2. Open the disk image and drag **Spark** into **Applications**.
3. Launch Spark and use your existing shell and tools.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP is provided for Sparkle updates; `SHA256SUMS` contains checksums for both downloads.

Codex and Claude Code are optional, installed and authenticated separately. Start them in a new zsh pane to connect metrics. Available fields depend on the CLI version and configuration. Restored workspaces open fresh shells; commands and agents are not automatically restarted.
