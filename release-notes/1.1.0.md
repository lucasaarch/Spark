# Spark 1.1.0

Spark 1.1 makes terminal workspaces easier to organize and navigate, with improved agent conversation recovery and Activity visibility.

## Highlights

- Drag terminal panes to rearrange tiled layouts and move panes between tabs.
- Keep focus on the preceding pane when closing the active terminal.
- Resume Codex and Claude conversations reliably with shells that use zsh instant prompt.
- Find running agents and recent conversations in Activity, with provider icons and deduplicated workspace entries.
- Keep tab titles steady when changing selection, with clearer keyboard-accessible selected state.

## Install

Requires **macOS 14 Sonoma or later**, on Apple Silicon or Intel.

1. Download **Spark-1.1.0.dmg** below.
2. Open the disk image and drag **Spark** into **Applications**.
3. Launch Spark and use your existing shell and tools.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP is provided for Sparkle updates; `SHA256SUMS` contains checksums for both downloads.

Codex and Claude Code are optional, installed and authenticated separately. Start them in a new zsh pane to connect metrics. Available fields depend on the CLI version and configuration. Restored workspaces open fresh shells; commands and agents are not automatically restarted.
