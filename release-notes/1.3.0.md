# Spark 1.3.0

Spark 1.3 adds a complete Git workflow around your terminal sessions, from branch and worktree management to review, conflict resolution, and commit history.

## Highlights

- Switch between local and remote branches from a searchable branch picker beside the agent usage indicator. Fetch remote branches or create and switch to a new branch from a dialog.
- Stage and unstage individual files or hunks, inspect staged and unstaged changes separately, and commit only the staged work.
- Compare branches and inspect commit history, including reviewing file diffs and safely reverting or undoing eligible commits.
- Resolve merge conflicts in the Source Control panel, manually or with the configured Codex or Claude Code provider.
- Search the current terminal and revisit commands entered during its session.
- Track commits ahead of or behind the upstream and fetch, pull, push, or publish branches to `origin` from Source Control.
- Create and manage Git worktrees, then review or merge worktree changes.
- Review file changes with status badges, per-file actions, and automatic updates as files change.

## Install

Requires **macOS 14 Sonoma or later**, on Apple Silicon or Intel.

1. Download **Spark-1.3.0.dmg** below.
2. Open the disk image and drag **Spark** into **Applications**.
3. Launch Spark and use your existing shell and tools.

The app and DMG are signed with Developer ID and notarized by Apple. The ZIP is provided for Sparkle updates; `SHA256SUMS` contains checksums for both downloads.

Codex and Claude Code are optional, installed and authenticated separately. Start them in a new zsh pane to connect metrics. Available fields depend on the CLI version and configuration. Restored workspaces open fresh shells; commands and agents are not automatically restarted.
